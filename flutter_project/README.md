# Web Developer Hub - Flutter Application Project

Ye complete unpacked folder structure hai jisko aap bina zip extract kiye directly use ya upload kar sakte hain.

## Folder Structure:
- `flutter_project/pubspec.yaml` -> Dependencies & package config
- `flutter_project/lib/main.dart` -> Complete UI, Tools, & Firestore code
- `flutter_project/android/app/build.gradle` -> Android build configuration (Play Store Ready)
- `flutter_project/android/app/src/main/AndroidManifest.xml` -> Permissions & App config

## Fast Commands:
```bash
# Dependencies install karein
flutter pub get

# Play Store release bundle generate karein
flutter build appbundle --release
```
